WHAT IS VECPORT

DBごとの違いを吸収する、共通レイヤー

VecPortは、Vector DBごとに異なるAPI、Filter、Migration方法を共通化するPython OSSです。アプリケーション側の移行負担を減らしながら、移行の計画・実行・検証を一つのワークフローにまとめます。

CAPABILITIES

移行作業に必要な判断と検証を共通化

単にVectorをコピーするのではなく、互換性、変換、再開、品質確認、納品レポートまで扱います。

01

Common API & Filter DSL

5種類のVector DBを共通APIで操作。$eq / $lt / $in / $and / $orなどのFilterをDBごとの差を吸収して利用できます。

02

Migration Control

Dry Run、Resume、進捗率、ETA、Conflict処理に対応し、途中経過を確認しながら移行を進めます。

03

Plan & Compatibility

Dimension、Distance Metric、Capabilitiesを移行前に診断し、実行可否と注意点を整理します。

04

Metadata Transform

rename、drop、default、int・float・boolなどの型変換を定義し、移行先に合わせてMetadataを整えます。

05

Verification & Quality

件数、ID、Vector、Metadataに加え、Recall@K、Top-1一致率、Top-K overlap、Latencyを比較します。

06

Code & Customer Report

既存Python検索コードの変更案を生成し、MigrationからRecall、Latencyまでを顧客向けReportに統合します。
